# Cartoon vector studies

Hand-drawn SVG interpretations of `../guild-cartoon-reference.png`, prepared as a separate preview before frontend replacement. These are simplified redraws, not exact image traces. No embedded raster images, external fonts, scripts, or image dependencies are needed for the mascot assets.

- `grub.svg`, `nib.svg`, `bonk.svg`: standalone transparent characters, matching 300 × 400 canvases.
- `goblin.svg`: head-only brand candidate with a tightly fitted canvas.
- `workshop.svg`: matching guild scene.
- `lineup.svg`: comparison sheet with labels.

Open in a browser or SVG editor. Named groups separate heads, clothes, props and limbs. The palette uses olive outlines, sage skin, cream aprons, rust clothing and wooden tools; no jewelry.

The frontend still uses `frontend/public/assets/`. These preview assets have not been installed there. Approve the drawing style first, then replace the five corresponding assets and check small brand/crew icons and mobile layouts.
